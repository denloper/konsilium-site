# Консилиум — лендинг

Статический одностраничный сайт: чистый HTML + CSS + JavaScript. Без фреймворков, без сборки, без внешних CDN — все шрифты и картинки лежат локально.

## Структура
```
index.html          — вся разметка и тексты
css/style.css       — стили, анимации, адаптив
js/main.js          — анимации появления, шапка, мобильное меню, параллакс, форма
assets/fonts/       — Inter, Manrope, Unbounded (WOFF, латиница + кириллица)
assets/img/         — логотип, экран приложения (webp + jpg), og.jpg для соцсетей
assets/favicon.ico, favicon-32.png, img/apple-touch-icon.png
```

## Как разместить
Загрузить содержимое папки (вместе с `index.html` в корне) на любой статический хостинг:
- **nginx/Apache** — скопировать в корень сайта (например `/var/www/konsilium`), `root` указать на эту папку. Дополнительная настройка не нужна.
- **Netlify / Vercel / Cloudflare Pages / GitHub Pages / Яндекс Object Storage** — просто загрузить папку.

Рекомендуется включить HTTPS и gzip/brotli-сжатие для `.html/.css/.js`.

Локальная проверка: `python3 -m http.server 8000` в этой папке → http://localhost:8000

## Что обязательно поправить перед запуском
1. **Домен** — в `<head>` файла `index.html` заменить `https://example.com` (canonical, og:url, og:image) на реальный.
2. **Контакты** — в футере (`<footer>`, отмечено комментарием `TODO`) заменить телефон и e-mail-заглушки, при необходимости добавить реквизиты юрлица.
3. **Политика конфиденциальности** — ссылка в футере сейчас `href="#"`; положить страницу и указать путь. Форма собирает персональные данные (152-ФЗ).

## Форма заявки
Форма (`#lead-form`, поля `name`, `phone`, `comment`, чекбокс согласия) **сейчас никуда не отправляет данные** — только проверяет поля и показывает «Спасибо».

Подключение: в `js/main.js` найти блок `TODO для программиста` и указать адрес обработчика:
```js
var FORM_ENDPOINT = 'https://ваш-сервер/api/lead';
```
Данные уходят `POST`-запросом в JSON: `{ "name": "...", "phone": "...", "comment": "..." }`.
Обработчиком может быть ваш backend, вебхук CRM (amoCRM, Bitrix24), Telegram-бот и т. п. При другом формате (FormData, другие поля) поправьте `fetch(...)` там же.

## Как править тексты
Все тексты — прямо в `index.html`, секции идут по порядку и имеют id:
`#top` (первый экран), `#problem`, `#cost`, `#solution`, `#vectors`, `#how`, `#app`, `#team`, `#emergency`, `#benefits`, `#pricing` (тарифы и цены), `#contact` (форма).
Фраза, выделенная градиентом, обёрнута в `<span class="gt">…</span>`.

Цвета — переменные в начале `css/style.css` (`--cobalt`, `--violet`, `--navy`, `--grad` …).

Экран приложения: заменить `assets/img/app.webp` и `assets/img/app.jpg` (пропорция ~ 9:19.5).

## Анимации
- Появление блоков при прокрутке (плавное проявление + сдвиг + размытие, каскадом) — класс `rv`, IntersectionObserver в `main.js`.
- Левитация телефона и стеклянных карточек, дрейф светящихся сфер, переливающийся градиент в заголовках, «бегущая» ЭКГ-линия, пульсация точек — CSS `@keyframes`.
- Параллакс первого экрана от мыши и прокрутки (только десктоп).
- Подъём/свечение карточек при наведении, стеклянная шапка с размытием, подсветка активного пункта меню.
- При системной настройке «уменьшить движение» (`prefers-reduced-motion`) все анимации отключаются.
